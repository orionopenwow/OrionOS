# Orion brand

The mark is the black hole as a circle with its photon ring, bright on the side turning toward you (left), and
Orion's belt (three stars) drifting toward its edge. The star nearest the hole is slightly stretched toward it.
Original design, made for Orion. Palette and fonts follow `docs/ORION_ART_UPDATE_PLAN.md` §6.

| Colour | Hex | Use |
|---|---|---|
| Void | `#05070E` | Background |
| Event | `#0B0F1E` | Raised background, icon field |
| Edge | `#262D50` | Lines; the stars in the light-paper mark |
| Accretion | `#7C5CFF` | Violet: the ring's far side, the "os" in the lockup |
| Photon | `#00E5FF` | Cyan: the ring's bright side, accents |
| Starlight | `#D8DEFF` | Wordmark and stars on dark |
| Ember | `#FFC66B` | The only warm colour, for things that need you (stuck, urgent) |

Type: the wordmark is Unbounded SemiBold, lowercase, with the "os" in Unbounded Regular. Fonts are in
`../fonts`.

## Files

`svg/` holds the sources, generated by `build.py`. Lockup text is outlined to paths, so no font is needed to
render them.

| File | What |
|---|---|
| `orion-icon.svg` | App icon: the mark on a deep-space rounded square |
| `orion-icon-small.svg` | App icon for 16–48 px: thicker ring, bigger stars, no secondary ring |
| `orion-mark.svg` / `orion-mark-small.svg` | Mark on transparent, for dark backgrounds |
| `orion-mark-light.svg` | Light paper and print: flat colours, no glow |
| `orion-lockup(-light).svg` | Mark + "orion" |
| `orion-os-lockup(-light).svg` | Mark + "orion os" |
| `orion-stacked.svg` | Mark above "orion" (splash, boot) |

`png/` holds the exports, made by `export.mjs` with headless Chromium:
- `orion-icon-{16…1024}.png`
- `orion-mark-{64…512}.png`
- `orion-mark-light-{256,1024}.png`
- the lockups at a height of 256 px
- `orion-stacked-512.png`
- `orion-splash-1080x1920.png` (mobile splash on Void)
- `orion-notify.png` (96 px, the mako notification icon)

To regenerate everything:

```sh
python3 os/theme/brand/build.py && node os/theme/brand/export.mjs
python3 os/theme/brand/android_icon.py             # Android adaptive icon + themed monochrome
cd apps/desktop && npx tauri icon ../../os/theme/brand/png/orion-icon-1024.png -o /tmp/icons
# copy 128x128*.png, 64x64.png, icon.icns and icon.png into src-tauri/icons; 32x32.png and icon.ico are built
# from the small variant (ImageMagick: convert orion-icon-{16,24,32,48,64,256}.png icon.ico)
```

## Where it is used
- Desktop app (Tauri): `apps/desktop/src-tauri/icons/*`
- Web favicons: `apps/desktop/public/favicon.svg`, `favicon-32.png`, `apple-touch-icon.png`; the docs site uses `docs/assets/favicon.png`
- Android: `apps/mobile/app/src/main/res/drawable/ic_launcher_{foreground,monochrome}.xml`, and the Android 12+
  splash in `values-v31/themes.xml`
- OS (other Art Update stages): `orion-notify.png` for mako; the mark and the stacked lockup for GRUB, Plymouth
  and the greeter
