# Orion Glass GTK theme: licence

- `Orion-Glass/gtk-*/adwaita-orion.css` is generated by `build-orion-glass.py` from GTK's built-in Adwaita-dark
  theme (GTK 3.24.41 / GTK 4.14.5 as shipped in Ubuntu 24.04), recoloured onto the Orion palette.
  GTK and its Adwaita theme are licensed **LGPL-2.1-or-later**; so are these derived files.
- `orion-glass.css`, the Solid twin and `build-orion-glass.py` are OrionOS's own work, under the same licence
  (LGPL-2.1-or-later) so the theme can be shipped as one piece.
- Check marks, slider knobs and other bitmaps are not copied: the CSS points at GTK's own built-in resources.
